# NutriTrack

## NutriTrack is a mobile nutrition tracking app that utilises AI to give recommendations and insights

## Features
Meal Tracking — Log meals and snacks throughout the day.
Nutrition Tracking — Monitor calories, protein, carbohydrates, fats, and other key nutrients.
Daily Goals — Set personalized nutrition targets and track your progress.
Progress Insights — Visualize your nutrition habits with clear, easy-to-understand summaries.
History — Review previous meals and nutrition data to identify patterns over time.
